# Muneeb Arif — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Features
- Premium dark navy / electric-blue design
- Responsive navigation for mobile, tablet and desktop
- Hero section using the included `images/hero-bg.png`
- About, skills, projects and contact sections
- Typing animation, scroll reveal and scroll progress indicator
- Contact form validation with `mailto:` integration

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension (recommended).
4. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in a modern browser.

## Important customizations
1. Open `script.js` and replace `YOUR_EMAIL@example.com` with your real email address.
2. Update the About section if you want to add your education or more personal details.
3. Replace planned project cards with real projects after you build them.
4. Add actual project repository links when those repositories are ready.
5. Adjust skill progress values in `index.html` to reflect your honest current level.

## Publish with GitHub Pages
1. Create a GitHub repository named `muneeb-arif-portfolio`.
2. Upload all files and the `images` folder, keeping the same folder structure.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the website.

## Contact form note
This starter form validates the fields and opens the visitor's default email application using a `mailto:` link. It does not store or send messages directly from the website. For a true hosted form, connect a form service or build a backend endpoint.
